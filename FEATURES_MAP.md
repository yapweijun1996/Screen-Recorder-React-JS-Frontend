# ScreenClip Pro Feature Map

This index maps user actions to the screens and code that implement them. Paths use English UI labels. All features run in the browser and have no application account or role requirement. Browser permissions, storage, and codec support apply where listed.

## Navigation

[App.tsx](src/App.tsx#L25) opens the recording surface by default and accepts `?page=converter` on initial load. Use the **ScreenClip Pro** and **WebM Converter** tabs in the header to switch surfaces. The **ScreenClip Pro** tab shows **Edit & Export** when a finished recording is loaded. The converter tab is disabled during capture setup, recording, pause, and capture finalization. [Navigation controls](src/App.tsx#L63)

## Editing and export

| Feature ID | User entry | Prerequisites and expected result | Negative case | Source |
| --- | --- | --- | --- | --- |
| `editor.preview` | **Edit & Export** → video preview, timeline ruler, or **Preview Selection** | A playable recording. Play, pause, seek, preview kept clips, or use **Enter fullscreen** where the browser supports it. | Invalid recording metadata surfaces a playback error and prevents processed export. | [Player](src/components/editor/EditorPlayer.tsx), [Preview action](src/components/editor/TimelineActions.tsx#L16), [Export validation](src/components/editor/useEditorExportController.ts#L23) |
| `editor.trim-clips` | **Edit & Export** → select a timeline clip and drag either edge | A valid recording duration. The kept region changes, and a completed drag becomes one undoable edit. | A handle press without a drag leaves the clip unchanged. | [Timeline clip](src/components/editor/TimelineClip.tsx), [Clip trim controller](src/components/editor/useClipTrim.ts), [Gesture cases](tests/clip-trim.test.mjs) |
| `editor.split-clips` | **Split at playhead** in timeline actions, or select **Blade** and click a clip | A cut inside the target clip. The playhead action splits the selected clip. Blade splits the clicked clip at the pointer, including an unselected clip. | A cut at a clip boundary cannot create a zero-length clip. | [Timeline actions](src/components/editor/TimelineActions.tsx#L38), [Blade toolbar](src/components/editor/TimelineToolbar.tsx#L63), [Clip hit handling](src/components/editor/ProTimeline.tsx) |
| `editor.remove-restore` | Select a timeline clip and use **Delete segment**. To remove a region, split around it first. Use **Undo** or **Reset Trim** to recover changes. | At least two kept clips for deletion. Deleted media is excluded from processed export. Undo restores the last edit, and Reset Trim restores the full range. | The last clip cannot be deleted through the toolbar or keyboard. | [Timeline actions](src/components/editor/TimelineActions.tsx), [Draft editing](src/components/editor/useSegmentsEditor.ts), [Segment rules](src/components/editor/segmentsState.ts) |
| `editor.timeline-navigation` | Timeline ruler, playhead, toolbar zoom controls or **Hand** tool | A loaded timeline. Click the ruler or drag the playhead to seek. Hover to skim in **Select** while paused. Zoom and drag in **Hand** mode to scroll horizontally. | A click in Hand mode leaves the playhead in place. Zoom controls disable at 50% and 1000%. | [Timeline](src/components/editor/ProTimeline.tsx), [Timeline interaction](src/components/editor/useTimelineInteraction.ts), [Zoom controls](src/components/editor/TimelineToolbar.tsx#L184) |
| `editor.keyboard-shortcuts` | With the editor active, press Space, J/K/L, arrow keys, or editing shortcuts | A loaded editor. Space toggles playback, J/K/L control shuttle playback, arrow keys step, A switches to **Select**, H switches to **Hand**, and Ctrl/Cmd+Z undoes an edit. | Text entry keeps its normal shortcuts. Reverse shuttle stays inside the selected clip. | [Playback keyboard handler](src/components/editor/useKeyboardShortcuts.ts), [Tool shortcuts](src/components/editor/useTimelineInteraction.ts) |
| `editor.retain-draft` | Make edits → **WebM Converter** tab → **ScreenClip Pro** tab | The same loaded recording in the same app session. Clip selections, undo history, playhead, and export settings are retained across the tab switch. | Reloading the page restores only the saved original. | [Draft provider placement](src/App.tsx#L139), [Editor draft](src/components/editor/EditorDraftContext.tsx), [Recording restore](src/components/useVideoSession.ts#L32) |
| `editor.export-processed` | **Export** → settings button, then **Export Trimmed** or **Export Full Video (No Trim)**. Use **Download** when ready. | A valid recording and compatible WebCodecs support. Choose quality, resolution, frame rate, and format where applicable. Video output may be MP4 or WebM depending on codec support. Audio-only export requires an audio track. | **Cancel export** aborts the current operation. An audio-only request without an audio track displays an error. | [Export inspector](src/components/editor/InspectorPanel.tsx), [Export controller](src/components/editor/useEditorExportController.ts#L23), [Format selection](src/services/webcodecs/webcodecExportService.ts) |
| `editor.download-original` | **Edit & Export → Export → Download Original (WebM)** | A current recording. Downloads the original WebM without encoding, including when the playback check fails. After a processed result is ready, use **Export another version** to return to the original download action. | The action is unavailable when no recording is loaded because the editor is hidden. | [Original download](src/components/editor/exportPanel/EditorExportFooterActions.tsx#L25), [Export result](src/components/editor/exportPanel/EditorExportStatus.tsx), [Editor visibility](src/App.tsx#L35) |
