https://github.com/Vanilagy/mediabunny/tree/9d36fc5779b254904bc609e66f2cd80ed8390b4b/packages/mp3-encoder

The extension repository documents building the original LAME source with
its MP3 decoder disabled, compiling the bridge, and creating the extension
package. The same instructions are in the README in the published npm
package. To replace the encoder in ScreenClip Pro, build that package with
the desired LAME encoder, install the rebuilt package in a local checkout of
ScreenClip Pro, then run npm run build to produce a replacement browser build.
